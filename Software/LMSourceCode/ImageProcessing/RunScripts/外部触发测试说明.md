# IMX296外部触发测试说明

## 测试原理
根据你的正确理解：
1. **MasterPi5 Pin 22** → **Connect Board Shr** → **Connect Board XTrg** → **SlavePi5 IMX296相机的XTrg引脚**
2. IMX296 Global Shutter相机支持硬件外部触发
3. 通过设置 `/sys/module/imx296/parameters/trigger_mode = 1` 启用外部触发模式

## 测试步骤

### 第一步：测试Pin 22触发信号
在**MasterPi5**上运行：
```bash
cd /mnt/projects/PiTrac/Software/LMSourceCode/ImageProcessing/RunScripts/
python3 test_pin22_trigger.py
```

选择测试模式（建议先选择"4️⃣ 单次触发测试"）来验证Pin 22能正常输出信号。

### 第二步：设置SlavePi5外部触发模式
在**SlavePi5**上运行：
```bash
cd /mnt/projects/PiTrac/Software/LMSourceCode/ImageProcessing/RunScripts/
sudo python3 test_slave_external_trigger.py
```

这个脚本会：
1. 设置IMX296为外部触发模式
2. 配置Picamera2等待外部触发
3. 监听来自MasterPi5的触发信号
4. 收到信号时自动拍照

### 第三步：同步测试
1. 先在**SlavePi5**上启动外部触发监听：
   ```bash
   sudo python3 test_slave_external_trigger.py
   ```

2. 然后在**MasterPi5**上发送触发信号：
   ```bash
   python3 test_pin22_trigger.py
   ```

## 预期结果
- MasterPi5发送Pin 22高电平信号
- Connect Board将信号路由到SlavePi5相机的XTrg引脚
- IMX296相机收到硬件触发信号后立即拍照
- 图像保存在 `/mnt/projects/PiTrac/test_images/` 目录

## 测试文件说明

### test_pin22_trigger.py (MasterPi5)
- 控制Pin 22输出高/低电平
- 支持单次、连续、交互式触发
- 可测试不同信号持续时间

### test_slave_external_trigger.py (SlavePi5)
- 设置IMX296外部触发模式
- 配置相机等待硬件触发
- 自动拍照并保存结果
- **需要sudo权限**

## 重要注意事项

1. **权限要求**：SlavePi5脚本需要sudo权限来设置IMX296触发模式
2. **触发模式**：测试完成后会自动恢复为内部触发模式
3. **信号时序**：建议触发信号持续100ms以上
4. **硬件连接**：确保Connect Board连接正确
5. **相机模块**：确保使用IMX296 Global Shutter相机模块

## 故障排除

### 如果SlavePi5没有拍照
1. 检查硬件连接（特别是Pin 22到Connect Board的连接）
2. 验证触发模式设置：
   ```bash
   cat /sys/module/imx296/parameters/trigger_mode
   # 应该显示 1（外部触发模式）
   ```
3. 检查相机权限和驱动
4. 验证MasterPi5的Pin 22是否正常输出

### 常见问题
- **权限错误**：确保SlavePi5脚本使用sudo运行
- **相机占用**：确保没有其他程序使用相机
- **驱动问题**：确保IMX296驱动已正确加载

## 预期同步性能
由于使用硬件触发，同步延迟应该非常小（通常<10ms），远优于软件GPIO监听方式。
