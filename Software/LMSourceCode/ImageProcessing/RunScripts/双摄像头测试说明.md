# PiTrac 双摄像头测试指南

## 概述

本文档说明如何测试PiTrac系统中的双摄像头功能。PiTrac使用两个摄像头：
- **摄像头1**: 可见光摄像头 (IMX296)，用于拍摄飞行中的高尔夫球
- **摄像头2**: 红外摄像头 (IMX296 NOIR)，用于拍摄地面上的高尔夫球

## 测试方法

### 方法1：使用简单的Shell脚本测试 (推荐)

这是最简单和最快速的测试方法：

```bash
cd Software
./test_dual_camera_simple.sh
```

这个脚本会：
- 使用libcamera-still命令分别测试两个摄像头
- 创建一个带时间戳的测试目录
- 保存两张测试图片
- 显示测试结果和图像文件信息

### 方法2：使用Python脚本测试

如果您需要更详细的图像分析：

```bash
cd Software
python3 test_dual_camera.py
```

这个脚本会：
- 测试两个摄像头
- 分析图像质量（亮度、对比度、清晰度等）
- 提供详细的测试报告

需要安装依赖：
```bash
pip3 install opencv-python numpy
```

### 方法3：使用现有的PiTrac系统脚本

如果您想使用完整的PiTrac系统来测试：

#### 测试摄像头1 (可见光)
```bash
cd Software/LMSourceCode/ImageProcessing/RunScripts
./runCam1Still.sh
```

#### 测试摄像头2 (红外)
```bash
cd Software/LMSourceCode/ImageProcessing/RunScripts
./runCam2Still.sh
```

### 方法4：手动使用libcamera-still命令

#### 测试摄像头1 (可见光)
```bash
libcamera-still --camera 0 --timeout 1000 --gain 3.0 --nopreview \
    --tuning-file=/usr/share/libcamera/ipa/rpi/pisp/imx296.json \
    --shutter 20000 --width 1456 --height 1088 --denoise cdn_off \
    --no-raw -o camera1_test.png
```

#### 测试摄像头2 (红外)
```bash
libcamera-still --camera 1 --timeout 1000 --gain 1.0 --nopreview \
    --tuning-file=/usr/share/libcamera/ipa/rpi/pisp/imx296_noir.json \
    --shutter 10000 --width 1456 --height 1088 --denoise cdn_off \
    --no-raw -o camera2_test.png
```

## 故障排除

### 常见问题及解决方案

#### 1. 摄像头未检测到
**错误**: `No cameras available`
**解决**: 
- 检查摄像头连接是否牢固
- 确认摄像头在设备树中已启用
- 运行 `libcamera-hello --list-cameras` 查看可用摄像头

#### 2. 权限问题
**错误**: `Permission denied`
**解决**: 
- 使用sudo运行命令
- 或者将用户添加到video组：`sudo usermod -a -G video $USER`

#### 3. 调试文件未找到
**错误**: `tuning file not found`
**解决**: 
- 检查调试文件路径是否正确
- 对于Pi 4，使用 `vc4` 路径
- 对于Pi 5，使用 `pisp` 路径

#### 4. 摄像头冲突
**错误**: `Camera in use`
**解决**: 
- 确保没有其他程序使用摄像头
- 杀死可能的libcamera进程：`sudo pkill libcamera`

### 检查摄像头状态

#### 查看可用摄像头


#### 查看摄像头设备
```bash
ls /dev/video*
```

#### 检查摄像头配置
```bash
vcgencmd get_camera
```

## 预期测试结果

### 成功的测试结果
- 两个摄像头都能成功拍照
- 图像文件大小合理 (通常50KB - 500KB)
- 图像清晰，没有明显的畸变
- 摄像头1拍摄的是可见光图像
- 摄像头2拍摄的是红外图像

### 图像质量指标
- **分辨率**: 1456x1088 像素
- **平均亮度**: 50-200 (取决于环境光照)
- **对比度**: >0.1
- **清晰度**: >100 (拉普拉斯方差)
