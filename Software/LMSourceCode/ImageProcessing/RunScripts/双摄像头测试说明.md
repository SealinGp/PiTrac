# PiTrac 双摄像头同步测试说明

## 测试目的
测试MasterPi5和SlavePi5之间的相机同步拍照功能，计算两个相机之间的拍照延迟。

## 硬件连接
根据接线图，已完成以下连接：
- **MasterPi5 Pin 22** → Connect Board → **SlavePi5触发输入**
- **MasterPi5 Pin 6 (GND)** → Connect Board → **SlavePi5 GND**
- 两个Pi都挂载了NAS: `/mnt/projects/PiTrac`

## 脚本文件
1. **test_dual_camera_sync.py** - MasterPi5上的主测试脚本
2. **test_slave_camera_listener.py** - SlavePi5上的监听脚本

## 使用步骤

### 1. 准备工作
确保两个Pi都已安装必要的库：
```bash
# 在两个Pi上都执行
sudo apt update
sudo apt install python3-pip
pip3 install picamera2 gpiozero opencv-python numpy
```

### 2. 启动SlavePi5监听器
在SlavePi5上执行：
```bash
cd /mnt/projects/PiTrac/Software/LMSourceCode/ImageProcessing/RunScripts/
python3 test_slave_camera_listener.py
```

看到以下输出表示监听器就绪：
```
✅ Slave Pi 监听器已就绪
⏳ 等待来自Master Pi的触发信号...
```

### 3. 运行MasterPi5测试
在MasterPi5上执行：
```bash
cd /mnt/projects/PiTrac/Software/LMSourceCode/ImageProcessing/RunScripts/
python3 test_dual_camera_sync.py
```

### 4. 查看测试结果
测试完成后会显示统计信息：
- 成功测试次数
- 平均延迟时间
- 延迟标准差
- 最小/最大延迟
- 同步性能评估

## 输出文件

- `master_*_*.jpg` - MasterPi5拍摄的图像
- `slave_*_*.jpg` - SlavePi5拍摄的图像

## 性能指标
- **优秀**: 平均延迟 < 50ms
- **良好**: 平均延迟 < 100ms
- **一般**: 平均延迟 < 200ms
- **需要优化**: 平均延迟 > 200ms

## 故障排除

### 常见问题
1. **相机初始化失败**
   - 检查相机模块连接
   - 确认相机已在raspi-config中启用

2. **GPIO权限错误**
   - 确保用户在gpio组中：`sudo usermod -a -G gpio $USER`
   - 重新登录或重启

3. **没有收到触发信号**
   - 检查GPIO连接线
   - 确认Pin 22连接正确
   - 检查SlavePi上的监听引脚配置

4. **图像保存失败**
   - 检查NAS挂载状态
   - 确认目录权限

## 注意事项
1. 确保两个Pi的系统时间同步
2. 测试前检查网络连接和NAS挂载
3. SlavePi监听器必须先启动
4. 测试期间保持硬件连接稳定
5. GPIO引脚号可能需要根据实际连接调整

## 预期结果
正常情况下，双相机同步延迟应该在50-100ms范围内。如果延迟过大，可能需要：
- 优化相机配置
- 检查系统负载
- 调整触发信号时序
- 优化网络通信
